<a id="distilled-prose-examples"></a>
# 提炼的文字示例

用示例识别原则，不当作文字模板。“适中”表示以当前位置必要的最少解释保留全部关键命题。

<a id="preserve-every-factual-clause"></a>
## 保留每个事实子句

**原文：**“协调器谨慎地按会话串行写入，在释放完成前刷入缓冲事件，并向调用方报告后端失败。”

**过度删减：**“协调器串行化持久化。”

**适中：**“协调器按会话串行写入，在释放完成前刷入缓冲事件，并向调用方报告后端失败。”

删装饰和重复，不删命题。主体、会话范围、释放顺序和失败可见性是独立事实。

<a id="explicit-skill-scope-is-functional"></a>
## 明确技能范围具有实际作用

**过度删减：**“读来源并判断。”

**适中：**“本技能是指导，不是完整清单。检查表之外仍须判断，已记录要求仍适用。”

**过多细节：**用数段论证为何清单无法代替独立思考。

保留明确限制，因为它改变代理应用流程的方式；删重复说服，不删行为约束。

<a id="a-cookbook-keeps-action-and-verification"></a>
## 操作指南保留动作与验证

**过度删减：**“给工具添加测试。”

**适中：**“单测验证注册和释放，经真实加载入口执行工具，渲染输出变化时加快照；断言观察外部结果，而非模型自报。”

**过多细节：**逐个讲解示例代码已显示的 fixture 文件和断言。

保留测试分层、必需动作、真实入口和可观察验证，移除 fixture 叙述。

<a id="preserve-ownership-and-timing"></a>
## 保留所有权和时机

**过度删减：**“释放期间取消提供方工作。”

**适中：**“运行时在释放子作用域前请求取消提供方工作；提供方仍负责在释放完成前等待其 worker 结束。”

**过多细节：**按时间顺序描述实现释放的每个 Promise 和回调。

主体、顺序、所有权转移点和完成保证是独立事实。

<a id="event-jsdoc-preserves-boundary-timing"></a>
## 事件 JSDoc 保留边界时机

**过度删减：**“组合并缓存会话前缀。”

**适中：**“在首次 pre-step 和模型请求之前组合一次会话前缀。监听器追加内容进入当前请求，pre-step 压力计量获得组合后的前缀。”

**过多细节：**逐步讲述实现顺序的循环辅助函数、缓存字段及 Promise 回调。

事件顺序及对当前请求的影响是调用方可见行为，不是实现叙述。

<a id="orient-complicated-code-without-narrating-it"></a>
## 为复杂代码提供方向，而不逐步复述

**过度删减：**“Worker realm 支持。”

**适中：**“拥有 worker realm 及宿主桥；realm 只初始化一次，释放终止 worker 并拒绝后续调用。协议理由见 worker 隔离笔记。”

**过多细节：**逐段预告后面类和辅助函数的内容。

保留模块角色、依赖、职责和非显然生命周期行为，架构理由链接来源，局部控制流交给代码。

<a id="public-jsdoc-includes-failures"></a>
## 公开 JSDoc 包含失败

**过度删减：**“返回 realm 全局对象。”

**适中：**“返回已初始化的 realm 全局对象；初始化未完成或 realm 已释放时抛错。”

**过多细节：**详细列出每次抛错的内部状态分支及辅助函数。

抛错和状态前置条件是调用方可见契约。

<a id="keep-a-concise-implementation-mapping"></a>
## 保留简洁实现映射

**过度删减：**“基于外部 API 的搜索提供方。”

**适中：**“将各提供方结果映射到共享搜索字段，保留标题、URL、文本，省略提供方专属排名元数据。”

**过多细节：**逐字段复述映射代码，包括同名字段和显然赋值。

保留能说明适配器在哪里丢弃或改变信息的映射细节。

<a id="link-rationale-while-keeping-the-local-contract"></a>
## 链接理由，保留本地契约

**过度删减：**“释放见生命周期笔记。”

**适中：**“释放会取消运行并等待提供方工作完全结束；所有权和竞态处理见生命周期笔记。”

**过多细节：**在每个释放器旁重复笔记的 Promise 调度和被拒所有权模型。

在调用方需要的位置保留行为和完成保证；算法和理由积极链接，链接不能替代本地契约。

<a id="implemented-agent-notes-retain-verification-contracts"></a>
## Implemented 笔记保留验证契约

**过度删减：**因为笔记已交付就删掉整个 Testing 章节。

**适中：**“单测覆盖发布前后取消、完全释放及提供方重载；构建入口冒烟覆盖真实加载路径。传输依赖进程，快照覆盖延后。”

**过多细节：**逐文件说明 fixture 和断言，却没有新增行为区分。

删迁移任务和测试过程叙述，保留测试层级、固定行为、真实入口及具名缺口。

<a id="a-security-boundary-may-need-one-concrete-example"></a>
## 安全边界可能需要一个具体例子

**过度删减：**“挂载插件共享宿主权限。”

**适中：**“挂载插件共享宿主权限，例如访问 ctx.shell 可使用宿主执行器权限执行命令。”

**过多细节：**枚举插件可能误用的所有服务及所有假想攻击。

一个例子能让抽象安全限制具有操作含义时，应保留。

<a id="delete-reasoning-transcripts-entirely"></a>
## 完全删除推理过程记录

**过多细节：**“循环先检查值是否缺失；缺失则下一分支提前返回，否则继续，因此最终断言安全。”

**适中：**代码已表达分支时无需注释；若提前返回保护非显然不变量，只写不变量。

不要把推理记录压成更短叙述，应删除。

<a id="configuration-comments-explain-what-the-tree-cannot"></a>
## 配置注释解释树本身未表达的内容

**过多细节：**相邻配置已显示顺序，却再写“先加载本地文件提供方，然后策略插件，然后 read/write/edit”。

**适中：**“在模型工具前加载策略，使 write/edit 经过先读后改门禁。”

保留顺序后果、非显然作用域规则或安全边界；配置清单由配置自身表达。

<a id="do-not-trim-for-word-count-alone"></a>
## 不只为字数而删减

**现有：**“适配器将提供方错误转换为共享类型，使调用方统一处理认证、限流和临时失败。”

**更短但更差：**“适配器规范化提供方错误。”

**适中决定：**除非链接或周边契约已列失败分类，否则保留原句；短句丢失后果和区别，没有改善结构。

<a id="model-visible-text-follows-ownership"></a>
## 模型可见文字遵循所有权

**过度删减：**“调用失败时工具返回错误。”

**过多细节：**把其他包的 schema 和渲染字符串复制进后端 README。

**适中：**引用本包拥有的稳定提示、结果和错误文本；schema 链接生成工具目录，其他包文字链接消费者 README，本地只说明本包条件或差异。

模型看到的文字是行为，但重复仍会漂移；精确原文应由所有者保存。

纯文字审计可指出可疑措辞，但无所属可执行快照时不得暗改。保持原文并报告延后，或扩大授权范围以包含所属情景及必需 GUI 证据。

<a id="generated-summaries-must-stand-alone"></a>
## 生成摘要必须独立完整

**过度删减：**“审批请求和策略服务。”正文稍后解释策略顺序及审计日志，但目录只导出首句。

**过多细节：**把完整生命周期和提示通知行为塞进被提取的句子。

**适中：**“审批服务先应用会话策略、再调用应答者，并将每组询问／结果记录到请求会话。”非目录细节留在后续句子。

明确生成器提取什么，片段须保留生成输出所需契约。

<a id="limitations-are-contracts-not-debt-inventories"></a>
## 限制是契约，不是技术债清单

**过度删减：**省略进程生命周期缓存导致配置变更需重载插件的事实。

**过多细节：**列私有辅助函数清理和未用测试访问器，却无调用方或维护者影响。

**适中：**“提供方选择在插件生命周期缓存，安装或修复提供方后需重载。”日常清理留在 TODO 或笔记。

保留影响使用或安全维护的缺口与非显然约束；包 README 不是积压任务堆。
